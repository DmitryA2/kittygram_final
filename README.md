# Kittygram — социальная сеть для котиков

## Описание проекта

Kittygram — это веб-приложение, позволяющее пользователям делиться фотографиями своих кошек, добавлять достижения и просматривать ленту других пользователей. Проект демонстрирует полный цикл контейнеризации и CI/CD с использованием Docker, GitHub Actions и развёртывания на удалённом сервере.

### Основные функции:
- Регистрация и аутентификация (токены).
- Добавление, редактирование и удаление записей о котиках.
- Загрузка изображений.
- Просмотр ленты с пагинацией.
- Админ-панель Django для управления контентом.

## Стек технологий

**Backend:**
- Python 3.9
- Django 3.2 + Django REST Framework
- Djoser (аутентификация)
- PostgreSQL 13
- Gunicorn

**Frontend:**
- React (сборка через `react-scripts`)
- Nginx (отдача статики и проксирование)

**DevOps:**
- Docker, Docker Compose
- GitHub Actions (CI/CD)
- Docker Hub (хранение образов)
- Nginx (gateway)

## Как развернуть проект

### Требования
- Установленные Docker и Docker Compose на сервере.
- Публичный сервер (VPS) с доступом из интернета (домен или IP).
- Репозиторий на GitHub.
